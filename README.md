# Пошаговый план — мини-приложение для подруги

Это будет самостоятельное приложение (не Telegram-бот). Подруга или её клиенты открывают ссылку, добавляют её на главный экран телефона — и дальше пользуются как обычным приложением, без всякого Telegram внутри. Кнопка «Написать в личку» просто открывает чат с ней напрямую.

Файлов теперь четыре, все должны лежать **в одной папке**:
- `index.html` — само приложение
- `manifest.json` — чтобы приложение можно было поставить на экран
- `icon-192.png`, `icon-512.png` — иконка приложения

---

## Этап 1. Посмотри, как выглядит (2 минуты)
Дважды кликни по `index.html` — откроется в браузере. Увидишь сетку из тестовых ароматов в 2 колонки. Это просто превью.

## Этап 2. Заполни каталог через Google Таблицу (10 минут)
1. Зайди на sheets.google.com → «Пустой файл».
2. В первой строке впиши столбцы ровно так, по-английски:
   `name | brand | vol1 | price1 | vol2 | price2 | vol3 | price3 | top | heart | base | stock | photo | desc`
3. Заполни по одной строке на флакон. Пример:
   - **name**: `Baccarat Rouge 540`
   - **brand**: `Maison Francis Kurkdjian`
   - **vol1 / price1**: `2` / `900` (только цифры — «мл» и «₽» приложение добавит само)
   - **vol2 / price2**: `5` / `2100 ₽`
   - **vol3 / price3**: `10` / `3900 ₽`
   - **top**: `шафран, жасмин`
   - **heart**: `амбергрис`
   - **base**: `кедр, бензоин`
   - **stock**: `yes` или `no`
   - **photo**: ссылка на фото с Google Диска (см. инструкцию ниже) или можно оставить пустым на старте
   - **desc**: короткое описание аромата
4. Файл → «Поделиться» → «Опубликовать в интернете» → выбери лист → формат **CSV** → скопируй ссылку.

Так как объём в наличии у неё ограничен и часто меняется, в приложении объём не выбирается — клиент просто нажимает «Заказать» и видит подсказку уточнить наличие нужного объёма у продавца напрямую.

## Этап 3. Подключи таблицу и её Telegram-ник (3 минуты)
Открой `index.html` обычным текстовым редактором (Блокнот / TextEdit) и найди:
```
const SHEET_CSV_URL = "";
const TELEGRAM_USERNAME = "her_username";
```
- Вставь скопированную ссылку между кавычками в `SHEET_CSV_URL`.
- Замени `her_username` на её настоящий Telegram-ник без `@`.

Сохрани файл.

## Этап 4. Выложи папку в интернет (10 минут)
Нужен публичный адрес — проще всего через **GitHub Pages**:
1. Зарегистрируйся на github.com, если ещё нет аккаунта.
2. «New repository» → дай имя (например `perfume-shop`) → Public → Create.
3. «Add file» → «Upload files» → перетащи туда все 4 файла (`index.html`, `manifest.json`, `icon-192.png`, `icon-512.png`) одним разом.
4. Settings → слева Pages → Source: ветка `main`, папка `/root` → Save.
5. Через минуту обнови страницу — появится ссылка вида `https://твой-логин.github.io/perfume-shop/`.

## Этап 5. Установи как приложение на телефон (1 минута)
1. Открой полученную ссылку в браузере на телефоне.
2. **iPhone (Safari)**: кнопка «Поделиться» → «На экран Домой».
3. **Android (Chrome)**: меню (три точки) → «Добавить на главный экран».

На экране появится иконка с амфорой-флаконом — открывается на весь экран, без адресной строки браузера, как обычное приложение.

## Этап 6. Поделись с подругой
Просто пришли ей ссылку (или сразу покажи установленную иконку на телефоне) — она сможет показывать каталог клиентам и сама добавлять флаконы в ту Google Таблицу, без касания кода.

---

### Если позже захотите встроить это в Telegram как кнопку у бота
Тот же набор файлов подходит — нужно будет только дополнительно создать бота через **@BotFather** (`/newbot`) и в Menu Button прописать ту же ссылку с GitHub Pages. Это отдельный, необязательный шаг — можно сделать в любой момент, ничего не переделывая.

### Что можно улучшить позже
- Реальные фото флаконов — просто вставить ссылку в столбец `photo`.
- Свой домен вместо `github.io`.
- При 50+ позициях — можно перейти на Airtable вместо Google Таблицы.

## Как добавлять фото (для неё — без кода)

1. Сфотографируй флакон, сохрани фото на телефоне.
2. Открой приложение **Google Диск** (Google Drive) — если аккаунта нет, потребуется создать (обычная Gmail-почта).
3. Загрузи фото на Диск (кнопка «+» → «Загрузить файл»).
4. Нажми на фото правой кнопкой (или на телефоне — значок с тремя точками) → **«Открыть доступ»** / **«Поделиться»**.
5. В настройках доступа выбери **«Все, у кого есть ссылка»** — это важно, иначе фото не будет видно в приложении.
6. Скопируй появившуюся ссылку — она будет выглядеть примерно так:
   ```
   https://drive.google.com/file/d/1AbCdEfGhIjKlMnOpQrSt/view?usp=sharing
   ```
7. Вставь эту ссылку **как есть** в столбец `photo` напротив нужного флакона в таблице. Ничего конвертировать не нужно — приложение само распознает ссылку с Google Диска и покажет фото правильно.

**Совет по самим фото:** старайся снимать флакон по центру кадра, желательно квадратом (или потом можно обрезать в редакторе телефона) — так фото будет красиво смотреться в карточке.
